# Visual asset credits

BUILD v0.7 uses the **Snowplains isometric tileset** from the FLARE ecosystem for the playable winter settlement scene.

- Atlas runtime source: `igorko/flare-mod-noname/new_game_mod/images/tilesets/tileset_snowplains.png`
- Snowplains artist: rubberduck, based on original grassland assets by Clint Bellanger
- License: Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
- Original credits are preserved in the upstream FLARE repository.

The game code, construction/research logic, settlement layout, HUD, progression and interaction code in this repository are separate from the third-party art asset.
