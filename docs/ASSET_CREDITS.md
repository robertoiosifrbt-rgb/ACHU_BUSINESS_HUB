# Living Business City — asset provenance

The living-city redesign uses public-domain / CC0 assets only.

## Quaternius — Downtown City MegaKit

Source: https://quaternius.com/packs/downtowncitymegakit.html
License: Creative Commons Zero (CC0 1.0 Universal)

Web-optimized model copies used at runtime:
- `b_small.glb` — Building_Small_1
- `b_medium.glb` — Building_Medium_2
- `b_large.glb` — Building_Large_2
- `prop_ac.glb` — Prop_ACUnit

These optimized copies are served from the public `anshaneja5/skyline-run` repository, whose `CREDITS.md` maps them back to the Quaternius Downtown City MegaKit and records the CC0 license.

The project also retains the existing Retro Urban Kit assets already used by the previous 3D implementation for walls, garages, trucks, barriers, scaffolding and fallback props.

Road ribbons, interaction rings, fountain water, hit areas, glow markers and UI are generated by project code at runtime.
