# BUILD — v0.1

A tiny mobile-first browser city-building game.

## v0.1 gameplay

- 7×7 build grid
- HQ starting tile
- Resources: Credits, Wood, Food, Population
- Buildings: House, Lumber Yard, Farm, Market
- Passive resource production every second
- Level 1 → 3 progression objectives
- Inspect and demolish modes
- 35% construction refund on demolition
- Local save in the browser (`localStorage`)
- No dependencies and no build step

## Run

Open `index.html` in a browser, or serve the repository with any static host / GitHub Pages.
